# Excel Data Analytics Course

A complete collection of my work from the **Excel Data Analytics Course**, taking me from the basics of spreadsheets all the way to advanced tools like Power Query and Power Pivot. I have completed the full course, and this repository holds the exercises, workbooks and projects from every chapter.

## About This Course

The course covers Excel from the ground up with a focus on data analysis. It starts with how Excel is laid out and how to move around it, builds up through formulas, charts and pivot tables, and finishes with the advanced tools analysts use to clean, model and analyze large datasets. It ends with two hands-on projects that apply everything learned.

## Skills Gained

- Navigating Excel efficiently with the ribbon, menus and keyboard shortcuts

- Creating and customizing charts and graphs
- Organizing data with tables and conditional formatting
- Summarizing large datasets with pivot tables and pivot charts

- Building data models and writing DAX measures in Power Pivot
